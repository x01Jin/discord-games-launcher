# Getting Started

## First Launch

After [downloading and setup](./installation.md), start the app by double-clicking `dcgl.exe`.

## The Interface

The launcher has a dark-themed window with two main tabs.

### Catalogue Tab

Your game discovery area (only games with a Windows version are listed):

- **Search bar:** type to search 20,000+ games, with a live result counter
- **Game cards:** each card shows the game name and whether it is already in your library

### My Library Tab

Your personal game collection:

- **Game status:** shows which games are Running or Stopped
- **Controls:** double-click a card to start or stop it; right-click for more options
- **Toolbar:** Refresh the view, Repair the library, or Stop all games at once

### Top Bar

- **Sync catalogue:** downloads the game list from Discord (press it once after first launch to fill the catalogue)
- **Stats:** shows totals such as how many games are saved, how many are in your library, and how many are running
- **Bottom bar:** shows the same numbers at a glance

## Quick Start Guide

### Step 1: Search for a Game

1. Click the **Catalogue** tab
2. Type a game name in the search box (e.g. "Minecraft", "Cyberpunk 2077", "Valorant")
3. Results appear instantly as you type

### Step 2: Add to Library

1. Find your game in the results
2. Click its card to select it (select several to add in bulk), then click the **Add N selected to library** button — or double-click a single card, or right-click and choose Add to Library
3. The game is added instantly

### Step 3: Open Your Library

1. Click the **My Library** tab
2. You will see your newly added game
3. Its status shows **Stopped**

### Step 4: Start the Game

1. Double-click your game (or right-click and choose Start)
2. Its status changes to **Running** (green)
3. Check Discord — you should see "Playing [Game Name]" in your status within about 15 seconds

### Step 5: Stop the Game

1. Double-click the game again (or right-click and choose Stop)
2. Its status returns to **Stopped**
3. Your Discord status clears

## Running Multiple Games

You can run several games at the same time:

1. Add several games to your library
2. Start each one
3. Your Discord status shows all active games
4. Use **Stop All** to stop everything at once

## Everyday Use

### Finding Games

- Use partial names: "mine" finds "Minecraft", "Minecraft Dungeons", and more
- Clear the search box to browse everything you have saved

### Managing Your Library

- **Add games:** in the Catalogue tab, select cards and use the add button
- **Remove games:** in the Library tab, right-click a card and confirm removal
- **Check status:** running games show a green Running indicator
- **Repair:** if entries misbehave (wrong info, missing files), use the Repair button in the Library toolbar

### Updating the Game List

- **First launch:** press **Sync catalogue** to download all games (takes about 5-10 seconds)
- **Later:** press it again anytime for the latest list
- **Offline:** the launcher keeps working with the games it already saved

## Good to Know

### Performance

- Running games use very little CPU
- Each running game uses about 10-20 MB of memory for its little window
- Adding games is instant

### Discord Status

- Discord must be running to see the status
- Status appears within about 15 seconds of starting a game
- Some games take a little longer to be noticed
- Status clears when you stop the game or close Discord

### Safety

- Each running game is just a small window showing the game name — nothing harmful
- Your antivirus may flag these windows at first (a false alarm)
- If that happens, allow the launcher's data folder in your antivirus settings

## What to Do Next

2. **Build your library** — add 5-10 games you play most
3. **Test with Discord** — start a game and check your status
4. **Learn more** — read about everything the app can do in [Features](./features.md)
